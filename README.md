# 📬 Инста-дайджест-бот

Отдельный Telegram-бот, который два раза в неделю (понедельник и четверг, 10:00 по МСК)
присылает тебе:
1. Апдейт по твоему аккаунту @future.dentt (реальные подписчики, лучший ролик)
2. Свежие вирусные Reels (300к–10М просмотров) из HikerAPI
3. 2 готовых сценария Reels под свежие тренды

Все цифры — реальные, из HikerAPI. Тексты идей/сценариев пишет Groq (бесплатный AI),
опираясь только на реальные найденные данные.

---

## ✅ Шаг 1-2 уже сделаны

`BOT_TOKEN` (от @BotFather) и `GROQ_API_KEY` (с console.groq.com) уже получены и
проверены локально — бот с ними работает.

## Шаг 3. Загрузить код на GitHub (через браузер, без командной строки)

1. Зайди на [github.com/new](https://github.com/new) (войди в свой GitHub-аккаунт,
   если попросит).
2. **Repository name** — впиши, например, `insta-digest-bot`. Оставь репозиторий
   **Private** (переключатель). README/​.gitignore/​license — ничего не добавляй,
   оставь пустым. Нажми **Create repository**.
3. На следующей странице найди ссылку **«uploading an existing file»** (она есть в
   подсказке «…or push an existing repository») и нажми её — откроется страница
   загрузки файлов.
4. Открой Finder, зайди в папку `Desktop → Claude → ИНСТА-ДАЙДЖЕСТ-БОТ` и **перетащи
   в браузер** все файлы, КРОМЕ папок `.venv` и `__pycache__`:
   - `bot.py`, `database.py`, `hiker_helper.py`, `digest_helper.py`
   - `requirements.txt`, `Procfile`, `runtime.txt`
   - `.gitignore`, `README.md`
5. Внизу нажми **Commit changes**.

## Шаг 4. Подключить репозиторий к Railway (тоже через веб)

1. Зайди на [railway.app](https://railway.app), войди через GitHub.
2. Нажми **New Project → Deploy from GitHub repo**, выбери репозиторий
   `insta-digest-bot`, который только что создал.
3. Railway сам увидит `Procfile` и запустит бота как `worker` — ничего дополнительно
   выбирать не нужно.
4. Открой созданный сервис → вкладку **Variables** → добавь три переменные (кнопка
   **+ New Variable**):
   - `BOT_TOKEN` — твой токен от BotFather
   - `GROQ_API_KEY` — твой ключ Groq
   - `HIKERAPI_KEY` — твой токен HikerAPI (тот же, что уже используется в Claude Code)
5. После добавления переменных Railway автоматически передеплоит сервис — подожди
   1-2 минуты, во вкладке **Deployments** статус должен стать зелёным (Active).

## Шаг 5. Подписаться на дайджест

1. Найди своего бота в Telegram по username, который ты придумал в BotFather.
2. Напиши ему `/start` — бот запомнит твой чат и с этого момента будет присылать
   дайджест по расписанию (Пн и Чт, 10:00 МСК).
3. Чтобы проверить сразу, не дожидаясь расписания — напиши `/digest_now`.
4. Загляни в меню команд (кнопка ☰ рядом со строкой ввода в Telegram) — там тоже
   есть быстрый доступ к `/digest_now` и `/help`.

---

## Важно

- Каждый дайджест — это реальные платные запросы к HikerAPI (~8-10 штук за раз).
  Иногда проверяй баланс на [hikerapi.com/billing](https://hikerapi.com/billing).
- Groq бесплатный, но с лимитами — для 2 дайджестов в неделю более чем достаточно.
- Если после редеплоя бота на Railway дайджест «забудет» прошлые цифры для сравнения —
  это нормально, он просто в следующий раз посчитает изменения с нуля.
