# 📬 Инста-дайджест-бот

Два раза в неделю (понедельник и четверг, 10:00 по МСК) присылает тебе в Telegram:
1. Апдейт по твоему аккаунту @future.dentt (реальные подписчики, лучший ролик)
2. Разбор свежих вирусных Reels (300к–10М просмотров) из HikerAPI — о чём ролик, какой
   формат, как применить
3. 2 готовых сценария Reels под свежие тренды

Все цифры — реальные, из HikerAPI. Тексты идей/сценариев пишет Groq (бесплатный AI),
опираясь только на реальные найденные данные.

**Работает через GitHub Actions — абсолютно бесплатно, без сервера.** GitHub сам
по расписанию запускает скрипт `send_digest.py`, он собирает дайджест и отправляет
в Telegram, затем завершается. Ничего не может «упасть» или потребовать оплату —
никакого постоянно работающего процесса нет.

> ⚠️ Из-за этого команды `/digest_now` и `/help` прямо в Telegram больше не работают
> (для них нужен постоянно запущенный бот). Вместо этого дайджест можно запустить
> вручную кнопкой на сайте GitHub — см. шаг 3 ниже.

## Шаг 1. Загрузить обновлённый код на GitHub

Код уже лежит в репозитории `insta-digest-bot`, но раньше там был другой вариант
(для Railway). Нужно заменить файлы:

1. Открой свой репозиторий на github.com → `abdurasidlatypov-art/insta-digest-bot`
   (или как он у тебя называется).
2. Удали старые файлы, которые больше не нужны: `bot.py`, `database.py`, `Procfile`,
   `runtime.txt`, `bot_data.db` (если есть) — открой каждый файл, нажми на иконку
   корзины 🗑 справа сверху, затем **Commit changes**.
3. Через **Add file → Upload files** загрузи актуальные файлы из папки
   `Desktop/Claude/ИНСТА-ДАЙДЖЕСТ-БОТ` (всё, кроме `.venv` и `__pycache__`):
   - `send_digest.py`, `hiker_helper.py`, `digest_helper.py`, `snapshot_store.py`
   - `requirements.txt`, `.gitignore`, `README.md`
4. Папку `.github/workflows/digest.yml` через веб-загрузку проще всего создать так:
   нажми **Add file → Create new file**, в поле имени файла введи целиком
   `.github/workflows/digest.yml` (GitHub сам создаст нужные папки), вставь в
   содержимое файл `digest.yml` из этой же папки на компьютере, нажми
   **Commit changes**.

## Шаг 2. Добавить секреты (переменные) в GitHub — тоже через веб

1. В репозитории открой **Settings → Secrets and variables → Actions**.
2. Нажми **New repository secret** и добавь по очереди 4 секрета:
   - `BOT_TOKEN` — токен от @BotFather
   - `CHAT_ID` — `1031032715` (это твой Telegram-чат, уже определён)
   - `HIKERAPI_KEY` — твой токен HikerAPI
   - `GROQ_API_KEY` — твой ключ Groq

## Шаг 3. Проверить вручную

1. Открой вкладку **Actions** в репозитории.
2. Слева выбери workflow **Instagram digest**.
3. Справа нажми **Run workflow → Run workflow** — это запустит дайджест прямо сейчас,
   не дожидаясь расписания.
4. Через 20-30 секунд загляни в свой Telegram — должны прийти 2-3 сообщения.
5. Если что-то пошло не так — на той же странице будет запись запуска с логами,
   пришли мне скриншот, разберёмся.

Дальше всё будет происходить само — по понедельникам и четвергам в 10:00 МСК.

## Важно

- Каждый дайджест — это реальные платные запросы к HikerAPI (~8-10 штук за раз).
  Иногда проверяй баланс на [hikerapi.com/billing](https://hikerapi.com/billing).
- Groq бесплатный, но с лимитами — для 2 дайджестов в неделю более чем достаточно.
- GitHub Actions бесплатен для приватных репозиториев в пределах 2000 минут/месяц —
  наш запуск занимает около минуты, дважды в неделю это ничтожная доля лимита.
- Снимок метрик аккаунта (для сравнения «было/стало») сохраняется в файле
  `account_snapshot.json` прямо в репозитории — workflow сам его обновляет и
  коммитит после каждого запуска.
- Railway можно больше не использовать — если там ещё висит старый сервис, его
  можно удалить (Settings сервиса → Delete Service), чтобы не путаться.
